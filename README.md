# Proyecto Carrito de Compras

Repositorio oficial para la entrega de la práctica de programación, que contiene la lógica estructurada tanto en **C#** como en **Java (BlueJ)**, además de los diagramas de diseño del sistema.

## 📂 Estructura del Repositorio

* **`Codigo_CSharp/`**: Contiene la implementación de las clases en C# para Visual Studio (lógica del carrito, productos y detalles).
* **`Codigo_Java_BlueJ/`**: Contiene el proyecto completo desarrollado en BlueJ con todas las clases, archivos `.class`, `.ctxt` y el archivo de configuración `package.bluej`.
* **`Diagramas/`**: Almacena los diagramas de flujo y de casos de uso correspondientes al diseño del software.

## 🚀 Tecnologías y Herramientas Utilizadas
* **C#** (.NET)
* **Java** (BlueJ)
* **Draw.io** (Modelado de diagramas)
